# Rawtape

**The data behind every crypto move.**

Rawtape is the data layer for crypto traders: the information other charts estimate or leave out, on one live chart.

Liquidations that actually happened, not levels modelled from open interest. Whale positions, live on the chart. Walls: the prices the market keeps turning back from, on every timeframe, with absorption showing where buyers and sellers are fighting at them right now. And market events: conditions active traders build on, each shown as data with the facts behind it.
